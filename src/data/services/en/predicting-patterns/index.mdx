The same instinct for what comes next shows up in different places, on its own terms in each:

- Designing dashboards that put what matters first, anticipating what someone needs to see before they have to ask for it.
- Building web layouts where each section sets up what a visitor expects to find next, so the page reads the way they already think.
- Picking up guitar from zero during COVID, learning to hear where a pattern was going before I could play it.
